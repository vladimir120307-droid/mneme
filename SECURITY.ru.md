# Политика безопасности

> 🇬🇧 English version: [`SECURITY.md`](SECURITY.md)

## Поддерживаемые версии

Mneme — pre-1.0. Патчи безопасности получает только последняя минорная
ветка; старые релизы не сопровождаются.

| Версия | Поддержка |
|---|---|
| 0.1.x  | ✅ |
| < 0.1  | ❌ |

## Как сообщить об уязвимости

Пожалуйста, **не открывайте публичный issue** на security-проблемы.

Используйте приватный механизм GitHub Security Advisories:

1. Откройте https://github.com/vladimir120307-droid/mneme/security/advisories/new
2. Опишите проблему:
   - Затронутая версия
   - Шаги воспроизведения
   - Наблюдаемое воздействие (раскрытие данных, RCE, DoS и т.д.)
3. Мы подтвердим получение в течение 72 часов и стремимся выпустить
   патч в 30 дней. Дата согласованного раскрытия оговаривается отдельно.

Если механизм GitHub недоступен — пишите мейнтейнеру (адрес в профиле).
По возможности шифруйте чувствительные детали.

## Что в зоне действия

- Python-пакет Mneme, включая C++ расширение.
- REST-сервер (`mneme serve`).
- Дефолтные примеры конфигурации в `docs/`.

## Что вне зоны

- Upstream-проблемы в Ollama / OpenAI / sentence-transformers / SQLite —
  сообщайте напрямую тем проектам.
- Misuse: например, `mneme serve` в открытой сети без аутентификации.
  README и `docs/configuration.md` описывают ожидаемый сценарий
  развёртывания.
