# Launch playbook

Ready-to-post copy for each channel, ordered roughly by impact for an
open-source AI-infra project. Read the per-channel notes before
hitting "post" — wrong tone in the wrong place kills a launch.

| Channel | File | Best window (your local time) |
|---|---|---|
| Hacker News (Show HN) | [`hn.md`](hn.md) | Weekday, 08:00–11:00 ET |
| Reddit r/LocalLLaMA | [`reddit-localllama.md`](reddit-localllama.md) | Weekday 09:00–14:00 ET |
| Reddit r/Python | [`reddit-python.md`](reddit-python.md) | Weekend 10:00–14:00 ET |
| X / Twitter thread | [`x-thread.md`](x-thread.md) | Tue–Thu 13:00–16:00 ET |
| LinkedIn | [`linkedin.md`](linkedin.md) | Tue–Thu 08:00–10:00 ET |

## Don't

- Post the same hour on multiple channels. Stagger by 1-3 days so each
  audience gets a fresh story.
- Use marketing language ("revolutionary", "game-changer"). The HN/Reddit
  AI crowd ignores or downvotes that on sight.
- Claim things you can't reproduce. Numbers in the README are reproducible
  with `python benchmarks/vector_search.py`. Stick to those.
- Reply combatively to skeptical comments. The standard answers to
  "isn't this just X?" are in [`faq.md`](faq.md). Engage substantively.

## Do

- Have someone friendly upvote and a few starring contacts queued for the
  first 30 minutes — early signal matters on every ranking site.
- Have one good GIF or SVG ready. The `assets/demo.svg` works in any
  Markdown surface.
- Be reachable for the first 4 hours after posting. Q&A drives ranking.
